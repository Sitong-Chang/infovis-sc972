# Formative Evaluation Record

This file is a structured place to record the planned baseline-versus-redesign evaluation. No participant results have been collected yet.

## Primary task

Identify which prompt edit most strongly changed the visual mood while preserving the main subject, and explain what changed.

## Planned participants

Four to six DKU student proxies who have used or seen text-to-image systems. They will not be treated as representative of professional artists or a broader community.

## Planned procedure

1. Assign baseline and redesign task order using a simple counterbalanced sequence.
2. Ask each participant to complete comparable prompt-comparison tasks in both modes.
3. Record completion time, selected edit, short explanation, and confidence.
4. Ask which displayed information is recorded evidence and which is AI interpretation.

## Measures

| Measure | Recording method |
|---|---|
| Task accuracy | Correct/incorrect against the task key |
| Completion time | Seconds from task reveal to final answer |
| Explanation quality | Mentions both prompt change and visible image change |
| Governance comprehension | Correctly distinguishes evidence from interpretation |
| Confidence | 1–5 self-report after each task |

## Planned success criterion

The redesign will be considered promising if at least four of five participants identify the relevant edit and distinguish recorded preference evidence from AI-generated interpretation, without a substantial increase in median completion time.

Methods & claim boundaries

Why each view is here

Edit bars

Answer which revision directions dominate the current selection; clicking filters the other views.

Change scatterplot

Tests whether prompt-token change and model-caption change move together; it does not claim the prompt caused an image change.

Thread landscape

Reveals iteration length, edit sequence, and outlying transitions before close inspection.

Inspector + layers

Returns to exact records and lets the viewer separate source, computation, model interpretation, and regenerated demonstration.
